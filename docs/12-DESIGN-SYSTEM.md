# 12 — Design System

风格：现代简约、清晰、高效。

语义色：
Green success/healthy
Blue info/progress
Yellow waiting/warning
Red error/danger
Gray inactive/stopped

颜色不可作为唯一状态提示。

共享组件：Button/Input/Select/Dialog/Card/Table/Badge/StatusBadge/Alert/Toast/Skeleton/EmptyState/ErrorState/Progress/OperationProgress/Tabs/Tooltip/FormField/DateTime/Money/TrafficUsage。

危险操作统一 Danger + 明确后果确认。
